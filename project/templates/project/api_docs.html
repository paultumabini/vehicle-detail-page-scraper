API Documentation

Read scraped inventory data as JSON via token-authenticated GET requests.

Overview
  • Method: GET only
  • Auth: DRF token in the Authorization header
  • Rate limit: 100 requests per hour per user (override with DRF_THROTTLE_USER)
  • Required query params: webproviders and domains on every request
Your token

Send this value as Token <key> in the Authorization header.

Token {{ user|get_api_authtoken }}
Endpoint
Base URL and path

Primary endpoint (current project slug):

{{ api_endpoint }}

Legacy alias (same handler, permanent redirect target):

{{ api_legacy_endpoint }}
Authorization header

Add a request header with your token:

Authorization: Token {{ user|get_api_authtoken }}
Query string parameters

webproviders and domains are required.

  • List all providers and domains: {{ api_sample_url }}
  • Filter by one or more providers (comma-separated): {{ api_endpoint }}?webproviders=dealerinspire,nabthat,d2cmedia&domains=all
  • Single provider and single domain (site_id): {{ api_endpoint }}?webproviders=dealerinspire&domains=taylorautomall

Use webproviders=available with domains=all to discover active providers. Multi-provider requests require domains=all.

Examples
