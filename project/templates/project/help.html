Help & FAQ

Common questions about scraping, submitting targets, and day-to-day operation.

Web scraping
How does web scraping work?

A scheduled spider (crawler) visits each target site, extracts vehicle listing fields you selected on the scrape form, and stores the results for export and API access.

How long does a new crawler take to set up?

Most new web templates are ready within 24 hours, depending on site complexity and how much testing the provider layout needs.

How long does a scrape run take?

Static sites or provider APIs usually finish in seconds to a few minutes. Dynamic sites that need a browser (Playwright) can take minutes to hours depending on inventory size.

Does scraping always work?

No. Dealer sites change providers, redesign layouts, or add bot protection. A spider that worked yesterday may need maintenance after a site update. Check Last Run on the target site and open a support request if exports stop updating.

New scrape request
How do I fill out the form?
  • Account & URL — pick the dealership account and paste the live VDP listing URL.
  • Domain name — a unique, single-word site_id (primary key). Duplicates are rejected. For URLs like car-dealer.com, use a compact slug such as cardealer (no spaces or hyphens).
  • Web provider — choose from the list or type a new provider name; it is created automatically on submit.
  • Fields to scrape — check the inventory columns you need; use All / None on the toolbar to toggle quickly.
Operations
What does the Last Run column mean?

Last Run is the most recent crawl-related timestamp we have for that target — from spider logs or inventory writes. It updates after a scheduled crawl finishes, not while one is in progress. A date means the last attempt completed (even if it scraped zero items). — means no crawl has finished yet. Use the Status column for Pending, Paused, or Active.
